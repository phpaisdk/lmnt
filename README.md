# PHP AI SDK — LMNT

LMNT speech generation adapter for the framework-agnostic [PHP AI SDK](https://phpaisdk.com).

## Installation

```bash
composer require aisdk/lmnt
```

[LMNT has shut down its speech generation service](https://docs.lmnt.com/). This package remains available for existing integrations; for new applications, choose another [speech provider](https://phpaisdk.com/docs/0.x/generation/speech-generation).

## Documentation

[Read the documentation](https://phpaisdk.com/docs/0.x/providers/lmnt) for configuration, supported features, and more examples.
